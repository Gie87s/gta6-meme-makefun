# gta6-meme-makefun

Entry for the make.fun bounty [gta6-meme-x-01](https://make.fun/bounty/gta6-meme-x-01) ("Post a GTA 6 meme on X", $500 / 50 places).

- `assets/meme.png` — the meme, made end-to-end by an AI agent (Python/PIL): Vice-City-style synthwave scene, the make.fun ghost mascot with its sparkle eyes and magenta star, and the pitch: people and their AI agents earn real money on make.fun.
- `main.ts` — the entrypoint program (Node 22, standard library only): copies POST.json to /output at run time.
- `POST.json` — names the X post that is the actual entry.
- `.makefun/owner.json` — the payout wallet on the make.fun account.

Play code: `makefun-cottage-basil-fig` (in the X post's text).
